# Introduction to Linux

## What is Linux?

Linux is an open-source operating system that manages computer hardware and software resources.

It acts as a bridge between the user and the computer hardware, allowing programs and applications to run efficiently.

Linux was created by **Linus Torvalds** in 1991 and has become one of the most widely used operating systems in the world.

---

## What is an Operating System?

An Operating System (OS) is software that controls the hardware and provides services for applications.

Without an operating system:

* Applications cannot run properly.
* Hardware cannot communicate with software.
* Users cannot easily interact with the computer.

Examples of operating systems:

* Linux
* Windows
* macOS
* Android
* iOS

---

## Why Do We Need Linux?

Without Linux

The computer hardware exists, but there is no software to manage:

* Memory
* Storage
* CPU
* Devices
* Applications

The system becomes difficult to use.

With Linux

Linux manages:

* Hardware resources
* User accounts
* Running applications
* Security controls
* Network communication

This makes the system stable, secure, and efficient.

---

## Real-World Example

When you open a web browser on Linux:

```text
User
  │
```

## Why is Linux Important in Cybersecurity?

Linux is one of the most important operating systems in cybersecurity.

Many cybersecurity tools are built for Linux, and most servers on the Internet run Linux-based operating systems.

A cybersecurity professional uses Linux to:

* Perform security testing
* Analyze logs
* Monitor networks
* Manage servers
* Investigate incidents
* Automate tasks using scripts

Learning Linux is considered a fundamental skill for cybersecurity careers.

---

## Features of Linux

### Open Source

The source code is publicly available and can be modified by anyone.

### Multiuser

Multiple users can access the system simultaneously.

### Multitasking

Linux can run multiple programs at the same time.

### Secure

Provides strong permission and access control mechanisms.

### Stable

Linux systems can run for long periods without restarting.

### Portable

Linux can run on desktops, servers, mobile devices, and embedded systems.

Popular Linux distributions include:

## Linux vs Windows

| Feature        | Linux       | Windows       |
| -------------- | ----------- | ------------- |
| Source Code    | Open Source | Closed Source |
| Cost           | Free        | Paid License  |
| Security       | High        | Moderate      |
| Customization  | Extensive   | Limited       |
| Server Usage   | Very Common | Less Common   |
| Resource Usage | Lightweight | Higher        |
