# Lab Report – Linux File System Exploration

## Objective

To explore the Linux file system hierarchy and understand the purpose of important system directories.

---

## Commands Used

```bash
pwd
ls /
cd /
cd /home
cd /etc
cd /var
cd /tmp
cd /bin
cd /root
cd ~
```

---

## Tasks Performed

- Explored the Linux root directory.
- Navigated through important system directories.
- Identified configuration, log, binary, and temporary storage locations.
- Attempted access to restricted directories.
- Practiced Linux path navigation.

---

## Key Findings

- Linux uses a hierarchical file system structure.
- Configuration files are stored in `/etc`.
- Logs and variable data are stored in `/var`.
- Temporary files are stored in `/tmp`.
- Essential commands are stored in `/bin`.
- Access to `/root` is restricted for non-privileged users.
