# Lab 02 – Linux File System Exploration

## Objective

To explore the Linux file system hierarchy and understand the purpose of important system directories.

---

## Prerequisites

- Kali Linux
- Terminal Access
- Basic Linux Navigation Knowledge

---

## Commands Used

```bash
pwd

ls /

cd /

ls

cd /home
pwd

cd /etc
pwd

cd /var
pwd

cd /tmp
pwd

cd /bin
pwd

cd /root

cd ~
pwd
```

---

## Directories Explored

| Directory | Purpose |
|------------|----------|
| / | Root directory |
| /home | User home directories |
| /etc | System configuration files |
| /var | Logs and variable data |
| /tmp | Temporary files |
| /bin | Essential system commands |
| /root | Root user's home directory |

---

## Skills Gained

- Linux File System Navigation
- Understanding Linux Directory Structure
- System Administration Fundamentals
- Linux Permissions Awareness
- Linux Enumeration Basics

---

## Expected Outcome

Successfully navigate important Linux directories and understand their role within the operating system.
