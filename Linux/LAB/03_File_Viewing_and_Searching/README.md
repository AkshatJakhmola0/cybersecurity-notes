# Lab 03 – Basic Linux Commands

## Objective

To learn and practice commonly used Linux commands for gathering system information, identifying users and hosts, locating binaries, viewing command history, accessing documentation, and performing basic command-line operations.

---

## Prerequisites

- Kali Linux / Ubuntu / Any Linux Distribution
- Terminal Access
- Standard User Account

---

## Theory

Linux provides a large collection of built-in commands that allow administrators and security professionals to interact with the operating system efficiently. These commands help collect system information, identify users, locate files and binaries, access documentation, and perform administrative tasks.

Understanding these commands is essential for Linux administration, troubleshooting, incident response, and cybersecurity operations.

---

## Commands Used

```bash
date

cal

uname

uname -a

whoami

id

hostname

uptime

history

clear

man ls

echo "Hello Linux"

which ls

whereis bash
```
