# 05 Networking Basics

## Objective

Learn basic Linux networking commands used for troubleshooting, network discovery, and system administration.

## Topics Covered

- Viewing IP addresses
- Checking network interfaces
- Testing connectivity
- Viewing routing tables
- DNS lookups
- Checking open ports
- Monitoring network connections

## Commands Used

- ip addr
- ip route
- ping
- ss
- netstat
- host
- dig
- nslookup
- traceroute
- curl
- wget

## Skills Learned

- Network troubleshooting
- IP address identification
- Route analysis
- DNS resolution
- Connectivity testing
- Open port identification

## Lab Environment

- OS: Kali Linux
- User: kali
- Shell: zsh
