# Linux Commands Cheat Sheet

## Navigation

| Command | Description |
|----------|-------------|
| pwd | Show current directory |
| ls | List files |
| ls -la | Show hidden files |
| cd | Change directory |
| cd .. | Move one level up |
| cd ~ | Go to home directory |

---

## File Management

| Command | Description |
|----------|-------------|
| touch file.txt | Create file |
| mkdir test | Create directory |
| rm file.txt | Delete file |
| rm -r folder | Delete directory |
| cp file1 file2 | Copy file |
| mv old new | Rename/Move file |

---

## Viewing Files

| Command | Description |
|----------|-------------|
| cat file.txt | Display file |
| less file.txt | View large files |
| head file.txt | First 10 lines |
| tail file.txt | Last 10 lines |
| tail -f file.txt | Live monitoring |

---

## System Information

| Command | Description |
|----------|-------------|
| uname -a | Kernel information |
| hostname | Show hostname |
| whoami | Current user |
| id | User details |
| uptime | System uptime |
| date | Current date and time |

---

## Searching

| Command | Description |
|----------|-------------|
| find / -name test.txt | Find file |
| which ls | Locate executable |
| whereis bash | Locate binary and docs |
| grep root file.txt | Search text |
