# Lab Report

## Experiment Title

Study of the DRIVERQUERY Command in Windows

---

## Objective

To learn how to use the DRIVERQUERY command to display installed device drivers, view detailed driver information, verify digitally signed drivers, and display driver information in different formats. The experiment also aims to understand the importance of device drivers in Windows administration and cybersecurity.

---

## Tools Used

- Windows 11
- Command Prompt
- DRIVERQUERY Utility

---

## Commands Executed

```cmd
driverquery

driverquery /v

driverquery /fo csv

driverquery /si

driverquery /?
```

---

## Procedure

1. Opened Command Prompt.
2. Executed the `driverquery` command to list installed device drivers.
3. Executed the `driverquery /v` command to display detailed driver information.
4. Executed the `driverquery /fo csv` command to display driver information in CSV format.
5. Executed the `driverquery /si` command to view digitally signed drivers.
6. Executed the `driverquery /?` command to display the help menu.
7. Recorded the observations and captured screenshots for each command.

---

## Results

Successfully displayed the list of installed device drivers, viewed detailed driver information, displayed driver details in CSV format, verified digitally signed drivers, and reviewed the built-in help documentation. The experiment demonstrated how DRIVERQUERY can be used to inventory device drivers, troubleshoot driver-related issues, and support security investigations.

---

## Conclusion

The DRIVERQUERY command is a useful Windows command-line utility for viewing information about installed device drivers. It enables administrators to troubleshoot hardware and driver issues while allowing cybersecurity professionals to identify suspicious, outdated, or unsigned drivers during incident response and forensic investigations. Understanding DRIVERQUERY is valuable for Windows administration, system maintenance, security auditing, and digital forensics.
