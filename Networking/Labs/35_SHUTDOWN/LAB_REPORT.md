# LAB REPORT

## Experiment Title

Study of the SHUTDOWN Command in Windows Command Prompt

---

## Objective

To understand the working of the **SHUTDOWN** command and learn how to shut down, restart, log off users, cancel scheduled operations, and access remote shutdown management tools.

---

## Tools Used

- Windows 11 Home Single Language
- Command Prompt (CMD)

---

## Commands Executed

```cmd
shutdown /?

shutdown /a

shutdown /l

shutdown /s /t 60

shutdown /a

shutdown /r /t 60

shutdown /a

shutdown /i
```

---

## Procedure

1. Opened Command Prompt.
2. Displayed the SHUTDOWN help menu.
3. Tested the abort command.
4. Executed the logoff command.
5. Scheduled a system shutdown with a 60-second timer.
6. Cancelled the scheduled shutdown.
7. Scheduled a system restart with a 60-second timer.
8. Cancelled the scheduled restart.
9. Opened the Remote Shutdown Dialog.

---

## Results

- Successfully displayed all SHUTDOWN command options.
- Verified the functionality of the abort command.
- Demonstrated user logoff capability.
- Successfully scheduled and cancelled a shutdown operation.
- Successfully scheduled and cancelled a restart operation.
- Opened the Remote Shutdown graphical interface.
- All commands executed successfully.

---

## Conclusion

The **SHUTDOWN** command is an important Windows administration utility that allows administrators to control power operations locally and remotely. It supports system shutdown, restart, user logoff, scheduled operations, and remote administration. These capabilities make it useful for system maintenance, enterprise management, and incident response activities.
