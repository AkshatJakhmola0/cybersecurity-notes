# Observations

## 1. Display All File Associations (`assoc`)

- The command displayed all registered file extension associations in Windows.
- Each file extension was mapped to a corresponding file type.
- Hundreds of file associations were available on the system.
- This information helps identify how Windows recognizes different file formats.

---

## 2. ASSOC Help (`assoc /?`)

- The help command displayed the syntax of the ASSOC utility.
- It explained how to view and modify file associations.
- The command serves as a quick reference for administrators.
- It provides the correct format for using the ASSOC command.

---

## 3. TXT File Association (`assoc .txt`)

- The `.txt` extension was associated with `txtfilelegacy`.
- Text files are linked to a predefined Windows file type.
- Windows uses this mapping to identify text documents.
- The association can be viewed without modifying system settings.

---

## 4. EXE File Association (`assoc .exe`)

- The `.exe` extension was associated with `exefile`.
- Executable programs use this default Windows file type.
- This association is essential for launching applications.
- Any unauthorized modification could prevent executable files from opening correctly.

---

## 5. PDF File Association (`assoc .pdf`)

- No file association was found for the `.pdf` extension.
- The command displayed an appropriate message instead of returning an error.
- Some applications manage PDF associations outside the ASSOC utility.
- Missing associations may require verification during troubleshooting.

---

## 6. HTML File Association (`assoc .html`)

- The `.html` extension was associated with `htmlfile`.
- HTML documents are mapped to a dedicated Windows file type.
- This association determines how HTML files are handled.
- The mapping can be verified using the ASSOC command.

---

## 7. JPG File Association (`assoc .jpg`)

- The `.jpg` extension was associated with `jpegfile`.
- JPEG image files use a common Windows file type.
- The association enables Windows to recognize image files correctly.
- Viewing the mapping helps verify image file handling.

---

## 8. Python File Association (`assoc .py`)

- The `.py` extension was associated with `Python.File`.
- Python scripts were correctly recognized by the operating system.
- This association allows Windows to identify Python source files.
- File associations for scripting languages should be monitored during security assessments.
