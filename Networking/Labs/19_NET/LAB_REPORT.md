# Lab Report

## Experiment Title

Study of the NET Command in Windows

---

## Objective

To study and understand the NET command in Windows for viewing information about local user accounts, local groups, shared resources, account policies, and workstation configuration. The experiment also aims to understand the importance of the NET command in Windows administration and cybersecurity.

---

## Tools Used

- Windows 11
- Command Prompt
- NET Utility

---

## Commands Executed

```cmd
net

net help

net user

net localgroup

net share

net accounts

net config workstation
```

---

## Procedure

1. Opened Command Prompt.
2. Executed the `net` command to display all available NET subcommands.
3. Used `net help` to view the help menu and available administrative commands.
4. Executed `net user` to display local user accounts.
5. Used `net localgroup` to list all local security groups.
6. Executed `net share` to display shared folders and administrative shares.
7. Executed `net accounts` to view local account and password policy settings.
8. Used `net config workstation` to display workstation configuration details.
9. Recorded the observations and captured screenshots for each command.

---

## Results

Successfully displayed the available NET subcommands, listed local user accounts and security groups, identified shared resources, viewed account policy settings, and examined workstation configuration. The experiment demonstrated how the NET command provides valuable administrative and security-related information without modifying the system.

---

## Conclusion

The NET command is a powerful Windows command-line utility used for system administration, network management, and security auditing. It enables administrators and cybersecurity professionals to enumerate user accounts, security groups, shared resources, password policies, and workstation information. The knowledge gained from this experiment is useful for Windows administration, Active Directory environments, penetration testing, digital forensics, and incident response.
