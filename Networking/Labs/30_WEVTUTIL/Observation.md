# Observations – WEVTUTIL Command

## 1. Help Menu (`wevtutil /?`)

- Displayed the syntax and available WEVTUTIL commands.
- Explained options for querying, exporting, and managing Event Logs.
- Helped understand the command structure.
- Useful before performing log operations.

---

## 2. List Available Logs (`wevtutil el`)

- Displayed all available Windows Event Logs.
- Included standard logs such as Application, Security, Setup, and System.
- Listed hundreds of Microsoft component-specific logs.
- Confirmed that Windows maintains separate logs for different services and applications.

---

## 3. View System Log Configuration (`wevtutil gl System`)

- Displayed the configuration of the System log.
- Showed log file location and maximum size.
- Displayed retention and logging settings.
- Useful for understanding how the log is maintained.

---

## 4. Query Recent System Events (`wevtutil qe System /c:10`)

- Displayed the latest System events.
- Included Event IDs, providers, and timestamps.
- Helped identify recent operating system activities.
- Useful for troubleshooting system issues.

---

## 5. Query Recent Application Events (`wevtutil qe Application /c:10`)

- Displayed recent application-related events.
- Included information generated by installed applications.
- Helped monitor application errors and warnings.
- Useful during software troubleshooting.

---

## 6. Query Recent Security Events (`wevtutil qe Security /c:5`)

- Displayed recent Security log events.
- Included security-related activities such as authentication and auditing.
- May require Administrator privileges.
- Useful during security monitoring and forensic investigations.

---

## 7. Display General Log Information (`wevtutil gli System`)

- Displayed general information about the System log.
- Included log properties and metadata.
- Helped understand log characteristics.
- Useful for Windows Event Log management.

---

## 8. Overall Analysis

- WEVTUTIL successfully managed and queried Windows Event Logs.
- Different logs provided information about system, application, and security activities.
- The command is useful for system administration, troubleshooting, and cybersecurity investigations.
- Event Logs provide valuable evidence for incident response and digital forensics.
