# Lab 30 – WEVTUTIL Command

## Objective

To understand the Windows **WEVTUTIL** command and learn how to view, query, and analyze Windows Event Logs using Command Prompt.

---

## Prerequisites

- Windows 10/11
- Command Prompt (CMD)
- Administrator privileges (recommended)

---

## Theory

**WEVTUTIL (Windows Event Utility)** is a built-in Windows command-line tool used to manage Event Logs. It allows administrators to list available logs, display log configuration, query event records, export logs, archive logs, and clear logs.

Windows Event Logs play an important role in system monitoring, troubleshooting, incident response, and digital forensic investigations.

---

## Syntax

```cmd
wevtutil <command> [options]
```

Examples:

```cmd
wevtutil el

wevtutil gl System

wevtutil qe System /c:10
```

---

## Commands Used

```cmd
wevtutil /?

wevtutil el

wevtutil gl System

wevtutil qe System /c:10

wevtutil qe Application /c:10

wevtutil qe Security /c:5

wevtutil gli System
```

## Steps Performed

1. Displayed the WEVTUTIL help menu.

3. Viewed the configuration of the System log.
4. Displayed the latest 10 events from the System log.
5. Displayed the latest 10 events from the Application log.
6. Displayed the latest 5 events from the Security log.
7. Retrieved general information about the System log.
8. Analyzed the output of each command.

---

## Key Findings

- Windows contains hundreds of Event Logs for different services and components.
- Standard logs include **Application**, **Security**, **Setup**, and **System**.
- Event Logs store important information about system activities, errors, warnings, and security events.
- The System log contains operating system and hardware-related events.
- The Application log stores events generated by installed applications.
- The Security log records authentication and security-related activities.
- WEVTUTIL provides detailed information about log configuration and event records.

## Interview Questions

**Q1. What is WEVTUTIL?**  
A Windows command-line utility used to manage and query Windows Event Logs.

**Q2. Which command lists all available Event Logs?**

```cmd
wevtutil el
```

**Q3. Which command displays recent System events?**

```cmd
wevtutil qe System /c:10
```

**Q4. Why are Windows Event Logs important?**  
They provide detailed records of system, application, and security activities for monitoring and troubleshooting.

**Q5. Which Event Log is most useful during security investigations?**  
The **Security** log, as it records authentication, logon, privilege, and audit events.
